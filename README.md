# Portfolio Website

A modern, responsive, and dark-themed portfolio website for **Ananyot Floog (Sales Engineering)**, hosted on GitHub Pages.

## Features
- **Modern UI:** Clean, responsive design with a dark theme (default) and a light theme toggle.
- **Typography:** Built with [JetBrains Mono](https://www.jetbrains.com/lp/mono/) for a professional developer-centric look.
- **Sections:**
  - **Hero:** Personal introduction.
  - **Projects:** Showcase of key work.
  - **Contact:** Easy way to get in touch.
- **Tech Stack:** Vanilla HTML5, CSS3, and JavaScript (No frameworks).

## Deployment
This project is deployed using [GitHub Pages](https://pages.github.com/).

## Getting Started
To run this project locally:
1. Clone this repository: `git clone https://github.com/FloogACE/floog-simple-portfolio.git`
2. Open `index.html` in your web browser.
